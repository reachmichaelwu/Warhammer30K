# PanzerHammer

A turn-based hex battle in the style of Panzer Marshal, played with Horus Heresy units already stored in this repository. It is a separate page (`panzerhammer/index.html`) and does not replace the combat toolkit.

This is a playable prototype with one scenario, **The Iron Gate**: Imperial Fists (VII) against Iron Warriors (IV). It is not an implementation of the Horus Heresy tabletop rules.

## Run

From the repository root:

```bash
python3 server.py
```

Open [http://localhost:3000/panzerhammer/](http://localhost:3000/panzerhammer/). The toolkit remains at [http://localhost:3000/](http://localhost:3000/) and links to the battle.

Tests, with no extra packages:

```bash
node --test tests/panzerhammer.test.js
```

Regenerate the unit catalog after the source data files change:

```bash
node panzerhammer/tools/build-catalog.js
```

## How to play

Select a gold Imperial Fists unit. Green hexes are legal moves. Red hexes are enemies that unit can attack. A unit may move once and attack once. End the turn and the Iron Warriors reply. Restart keeps the same combat seed; New seed rerolls damage. Help and the unit codex are in the side panel.

Victory: destroy every Iron Warriors unit, hold all three strongpoints after their reply, or hold at least two when turn 10 ends. Defeat: lose every Imperial Fists unit, or finish turn 10 with fewer than two strongpoints.

### Importing a map later

The battle accepts two JSON formats:

- `panzerhammer-map-v1` — terrain, size, and objectives. The current units are redeployed onto the same coordinates if every hex is still legal. See `engine.js` `normalizeMap`.
- `panzerhammer-scenario-v1` — a map plus an `order` array of `{ instanceId, catalogId, side, col, row }`.

Terrain letters in a row string: `.` clear, `r` road, `b` rubble, `t` woods, `f` fort, `w` wall, `g` gate, `u` water, `n` trench. Walls and water block everyone. Vehicles cannot enter woods or bastions. This is not the OpenPanzer XML scenario format.

## Where the units come from

The catalog (`catalog.js`) is generated from files already in this repo. Numbers are copied, not rewritten to look more official.

| Piece | File |
| --- | --- |
| Names, model counts, categories | `02-unit-presets.js` |
| Points | `04-points.js` |
| Characteristics | `27-new-recruit-stats-data.js` (`NEW_RECRUIT_UNIT_STATS`), pinned from BSData horus-heresy-3rd-edition. See `new-recruit-stats-reference.json`. |
| Representative shooting weapon | First shooting row in `05-weapon-profiles.js` `LEGION_WEAPON_PROFILES`, otherwise `07-army-builder-data.js` `WEAPON_PROFILES`. Names containing Maximal, Frag, or Fury of the Legion are skipped when another row exists. |
| Range | Matching armoury entry in `15-main-app.js` when the builder can see one; otherwise `getWeaponRangeInfo` in `05-weapon-profiles.js`. |
| Melee name, WS, S, A, AP | First row in `12-charge.js` `MELEE_WEAPON_PROFILES`. |
| Portraits | Paths already listed in `17-artwork.js` and `legions/`. No new art was downloaded. |

Sigismund, Fafnir Rann, Alexis Polux, and the Warsmith have no shooting row of their own. The catalog flags a Bolt Pistol copied from the Despoiler Squad profile (`WEAPON_PROFILES.despoiler`) and says so in the codex.

The enemy Rapier is the Solar Auxilia Rapier Carrier (`Solar Auxilia.json` / `SA: SUPPORT`), used here as an allied battery. Its name in the codex is the preset name, Auxilia Rapier Section.

The codex also lists Templar Brethren, Fafnir Rann, Alexis Polux, a Sicaran, and a Centurion so later scenarios can add them without a new data pass. They are not deployed in The Iron Gate.

## Conversion used in play

These formulas are specific to PanzerHammer. They are not hidden tabletop modifiers.

- **Move:** `max(2, round(M / 2.5))` hexes. If the model type contains "Heavy", subtract 1, still at least 2. Tactical Squads (M7) move 3. Breachers and Phalanx Warders (Heavy) move 2. Predators (M12) move 5.
- **Hit points:** vehicles use listed HP. A single model uses W. A squad uses models × W. A Tactical Squad is 10 HP because the preset is 10 models at W1.
- **Range:** `max(1, round(inches / 8))` hexes. Template weapons are 1 hex. A 24" bolter is 3 hexes. A 48" lascannon is 6.
- **Ranged score:** shots + S + floor(BS / 2) + Damage. Heavy, Ordnance, and Barrage weapons lose 3 after the unit moves.
- **Melee score:** the charge-table WS + A + floor(S / 2). If that row is missing, the model's own WS, A, and S are used.
- **Defense:** infantry and walkers use T + a save bonus (2+ is +3, 3+ is +2, 4+ is +1) + 1 if an invulnerable save is listed, plus terrain cover. Vehicles use front armour − 5, plus half the cover, rounded down.
- **Cover:** rubble +1, thorn scrub and trenches +2, the gate +2, bastions +3.
- **Damage:** 2d6 + score − defense. 14+ deals 4, 11+ deals 3, 8+ deals 2, 5+ deals 1.
- **Armour facing:** against a vehicle, S at or above front armour keeps that damage; S within 4 of front armour loses 1 damage (minimum 1); S within 8 glances for 1; weaker shots do not wound. A bolter does not wound a Predator (front 13). A lascannon does.
- **Saves:** a non-vehicle save of the listed value or higher on 1d6 reduces damage by 1. Armour saves are ignored when a numeric AP is less than or equal to the save, which is the old "AP beats that save" shortcut, not the 3rd-edition damage-mitigation procedure. Invulnerable saves are not ignored. Vehicles do not take that save.
- **Zones of control:** entering a hex next to an enemy ends the move. A unit that starts next to an enemy must leave contact before it can move elsewhere.
- **Line of sight:** curtain walls, thorn scrub, and other units block the hexes between shooter and target.

## Extending

Add a unit id to `IDS` in `panzerhammer/tools/build-catalog.js` and regenerate. Add another `panzerhammer-scenario-v1` file and point `ui.js` at it, or import it from the button. The engine API used by tests is `createGame`, `legalMoves`, `legalAttacks`, `moveUnit`, `attackUnit`, `endPlayerTurn`, and `finishAiPhase`. The opponent lives in `ai.js`.

## Limitations

- One scenario, one simple opponent, no campaigns, supply, experience, or transport.
- One representative weapon per unit, not the wargear options in the army builder.
- Flyers are rejected at deployment.
- Combat is a single opposed roll, not the shooting, wound, and vehicle-damage tables in the toolkit.
- The Panzer Marshal map was not used. See the license table above.
- Artwork is whatever this repository already shipped. PanzerHammer does not add a license for it.
